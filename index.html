    Sumber data

    Harus sama persis dengan MQTT_TOPIC di firmware. Broker publik bersifat terbuka, gunakan topic yang sulit ditebak.
    Hanya jalan jika halaman dibuka dari http:// atau file lokal. Dari GitHub Pages (https) akan diblokir browser.
    Setelah menekan Simpan, browser akan meminta memilih port COM ESP32.
